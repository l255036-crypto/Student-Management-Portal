# Student-Management-Portal 

## Project Overview

The Student Management Portal is a Python-based application developed as part of Assignment No. 3. A Python-based Student Management Portal allows users to securely log in and manage student records through features like adding, viewing, searching, updating, and deleting records. It uses CSV file handling for data storage and management.# Student Management Portal

## Features

Admin Login: Provides a login mechanism to access the portal.
Add Student: Add new student records to the system.
View Students: Display all available student records.
Search Student: Find a student using the available search functionality.
Update Student: Modify existing student information.
Delete Student: Remove student records.
Generate Reports: Generate reports based on stored student data.
CSV File Handling: Store and retrieve student records using a CSV file.

## Technologies Used

- Python 3
- Jupyter Notebook
- CSV Module
- GitHub

## How to Run the Project

1. Download this repository to your computer.
2. Make sure Python 3 and Jupyter Notebook are installed.
3. Open Jupyter Notebook.
4. Navigate to the downloaded project folder.
5. Open the Student Management Portal notebook.
6. Make sure `students_new.csv` is in the same directory as the notebook.
7. Run the notebook cells in order.
8. Follow the on-screen instructions to access and use the portal.
